# Skeleton Traductor

Traductor de juegos para Windows: Unity, Ren'Py, RPG Maker, KiriKiri y Wolf RPG.

## Descargar

Ve a **Releases** y descarga la ultima version portable:

- `SkeletonTraductor_0.5.0_Portable.zip`
- SHA-256: `CC562BE0A3C44F2EED5F83707C6A592E9AAC2B0710742EB6C0082A83E58C68D3`

Descomprime el ZIP en una carpeta con permisos de escritura y ejecuta:

```bat
Iniciar.cmd
```

No necesitas instalar Python ni nada mas. No se incluyen juegos ni traducciones de terceros.

## Free y Pro

La version **Free** permite extraer texto, editarlo a mano e inyectarlo.

La version **Pro** se desbloquea con una licencia valida desde **Ajustes → Licencia**. La licencia se verifica sin conexion. La descarga no incluye el generador de claves ni las claves privadas.

## Actualizaciones

La aplicacion consulta `latest.json` para saber si hay una version nueva. Las actualizaciones se publican como archivos ZIP en Releases, nunca dentro del historial del repositorio.

Este repositorio solo contiene la distribucion y los metadatos de actualizacion; no contiene el codigo fuente ni datos de usuarios.
